🔍 О процессе

Процесс Холла-Эру: Электролиз расплавленного глинозёма (Al₂O₃) в криолите (Na₃AlF₆).

Катод: Al³⁺ + 3e⁻ → Al(ж) | Анод: C + O²⁻ → CO₂ + 2e⁻

Общая реакция: 2Al₂O₃ + 3C → 4Al + 3CO₂

Ключевые формулы:

η = η₀ + Δηₜ + Δη꜀ | E_уд = (U × 1000) / (g_Al × (η/100)) | Расход_анода = 334 / (η/100)

Видео: Галилео. Алюминий Видео: Принцип электролиза
