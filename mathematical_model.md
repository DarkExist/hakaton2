# Описание математической модели для `calculator.py`

Этот документ описывает математические модели, реализованные в проекте.

## 1. `calculate_eta` (Расчет выхода по току)

Эта функция вычисляет выход по току ($\eta$) на основе температуры электролита ($T$) и концентрации глинозема ($C$). Расчет является кусочно-заданным и включает начальное значение `ETA0` и корректировки, основанные на отклонениях от оптимальных диапазонов.

**Начальное значение:**
$\eta_{начальное} = \text{ETA0}$

**Влияние температуры:**
*   Если $T = 960^\circ C$: Без изменений.
*   Если $T > 960^\circ C$: $\eta = \eta - (T - 960) \times 0.5$
*   Если $950^\circ C < T < 960^\circ C$: $\eta = \eta - (960 - T) \times 0.3$
*   Если $T \le 950^\circ C$: $\eta = 70$ (критический сбой: риск застывания электролита)

**Влияние концентрации:**
*   Если $3.5 \le C \le 4.5$: Без изменений.
*   Если $3.0 \le C < 3.5$: $\eta = \eta - (3.5 - C) \times 0.5$
*   Если $C < 3.0$: $\eta = 60$ (критический сбой: риск анодного эффекта)

**Финальное ограничение:**
Финальное значение $\eta$ ограничивается диапазоном от 60% до 95%:
$\eta = \max(60, \min(95, \eta))$

**Выходные данные:**
Функция возвращает округленное значение $\eta$, булевые флаг `critical_failure` и `warning_message`.

## 2. `calculate_energy_consumption`

Эта функция рассчитывает удельное потребление энергии ($E$) на килограмм произведенного алюминия.

**Формула:**
$E = \frac{V \times 1000}{G_{Al} \times (\eta / 100)}$

Где:
*   $E$: Удельное потребление энергии (кВт·ч/кг)
*   $V$: Напряжение (Вольт)
*   $G_{Al}$: Электрохимический эквивалент алюминия (г/А·ч)
*   $\eta$: Выход по току (в процентах, например, 90 для 90%)
*   $1000$: Коэффициент пересчета

**Выходные данные:**
Функция возвращает округленное целочисленное значение удельного потребления энергии.

## 3. `calculate_anode_consumption`

Эта функция рассчитывает удельное потребление анода ($A_c$) на килограмм произведенного алюминия.

**Формула:**
$A_c = \frac{334}{\eta / 100}$

Где:
*   $A_c$: Потребление анода (кг анода / кг Al)
*   $334$: Эмпирическая константа (кг C / кг Al) на основе типичных значений.
*   $\eta$: Выход по току (в процентах, например, 90 для 90%)

**Выходные данные:**
Функция возвращает округленное целочисленное значение удельного потребления анода.

## 4. `calculate_productivity`

Эта функция рассчитывает производительность электролизера ($P$) в тоннах алюминия в сутки. Она включает расчет теоретической производительности и последующую корректировку ее с учетом выхода по току для получения фактической производительности.

**Теоретическая производительность ($P_{теор}$):**
$P_{теор} = \frac{I \times 24 \times G_{Al}}{1000}$

**Фактическая производительность ($P_{факт}$):**
$P_{факт} = P_{теор} \times (\eta / 100)$

Где:
*   $P_{факт}$: Фактическая производительность (тонн Al/сутки)
*   $P_{теор}$: Теоретическая производительность (тонн Al/сутки)
*   $I$: Сила тока (килоамперы, кА)
*   $24$: Количество часов в сутках
*   $G_{Al}$: Электрохимический эквивалент алюминия (г/А·ч)
*   $1000$: Коэффициент пересчета (г в кг, кг в тонны)
*   $\eta$: Выход по току (в процентах, например, 90 для 90%)

**Выходные данные:**
Функция возвращает округленную фактическую производительность с одним знаком после запятой.
